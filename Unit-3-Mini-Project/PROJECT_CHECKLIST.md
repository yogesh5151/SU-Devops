# Submission Checklist

Use this checklist only after completing the corresponding real-world step.

- [ ] GitHub repository contains `app/`, `database/`, `tests/`, `k8s/`, `Dockerfile`, and `Jenkinsfile`.
- [ ] Branch progression is visible in Git history.
- [ ] Pull request / merge evidence is available if required by the portal/instructor.
- [ ] Jenkins successful multi-stage build screenshot captured.
- [ ] Jenkins JUnit test report screenshot captured.
- [ ] `docker images` output captured.
- [ ] `docker ps` output captured with the running project container.
- [ ] `kubectl get pods` shows 3 healthy replicas.
- [ ] Pod deletion and self-healing evidence captured.
- [ ] Technical project report completed.
- [ ] Final GitHub repository URL recorded in the report.
